# ♟️ Chess Game

A browser-based Chess Game built with **HTML**, **CSS**, and **JavaScript**. The game implements the standard rules of chess, including legal piece movement, captures, check detection, and turn-based gameplay.

## 📖 About the Project

This project is a classic two-player chess game that runs directly in the browser. It uses JavaScript to handle the game logic and HTML/CSS to render the chessboard and pieces.

Players take turns moving pieces according to official chess rules while the game validates legal moves and prevents illegal ones.

---

## ✨ Features

- ♟️ Standard chess board
- 👥 Two-player gameplay
- 🔄 Turn-based movement
- ✅ Legal move validation
- 👑 Check detection
- 🏰 Castling support
- 🛡️ Prevents illegal moves that expose the king
- 🎨 Interactive chessboard
- 💻 Runs entirely in the browser
