# chess_game
chess
Overview

This project is a fully-featured Chess game engine implemented for the web. It supports complete official chess rules, move validation, and game-state management. Designed with scalability and clean architecture in mind.

⚙️ Core Features
♟️ Game Logic
Full legal move validation (all pieces)
Turn-based system (White / Black)
Check, Checkmate, and Stalemate detection
Draw conditions:
Insufficient material
Threefold repetition (if implemented)
50-move rule (optional)
